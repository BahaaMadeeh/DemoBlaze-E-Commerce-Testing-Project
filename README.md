# DemoBlaze E-Commerce Testing Project

## Project Overview

This project demonstrates a complete Software Quality Assurance (QA) process applied to the DemoBlaze E-Commerce Platform. The objective was to analyze requirements, design test cases, execute tests, identify defects, and produce professional QA deliverables following industry-standard testing practices.

## Scope

The project covers key business functionalities including:

* User Authentication (Login)
* Product Browsing
* Shopping Cart Management
* Checkout and Purchase Workflow

## Testing Activities

* Requirements Analysis
* User Story Creation
* Functional Testing
* Negative Testing
* Edge Case Testing
* Usability Testing
* Regression Test Planning
* Defect Management
* Requirements Traceability

## Deliverables

* User Stories
* Functional Test Cases
* Test Execution Report
* Defect Log
* Requirements Traceability Matrix (RTM)
* Usability Testing Report
* Regression Testing Strategy
* Release Report
* JIRA/Xray Traceability Documentation
* Release Enhancement Proposal

## Tools Used

* JIRA
* Xray
* Microsoft Excel
* Microsoft Word
* Microsoft PowerPoint

## Key Outcomes

* Designed and executed test cases for critical business workflows.
* Identified and documented defects with severity and priority classification.
* Established requirement-to-test-to-defect traceability.
* Evaluated usability issues and proposed product improvements.
* Produced comprehensive QA documentation supporting release readiness assessment.

## Skills Demonstrated

Software Testing, Manual Testing, Functional Testing, Regression Testing, Defect Tracking, Test Case Design, Requirements Analysis, RTM, JIRA, Xray, Agile Testing, Test Reporting, and Quality Assurance.
